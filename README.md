# CSMAR 期货交易助手（Chrome 扩展）

希施玛投资交易仿真平台（https://vetp.csmar.com）的个人交易辅助工具。

当前版本：**v1.6.0**

## 安装

1. 地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择**本文件夹**（就是包含 manifest.json 的这一层）

## 不能做的事

- **不要移动或删除这个文件夹**。Chrome 记录的是这个绝对路径，挪走扩展就失效。
  确实要挪：挪完后到 `chrome://extensions` 移除再重新加载一次。

## 改代码

- 全部逻辑都在 `content.js`，改完保存 → 到 `chrome://extensions` 点扩展卡片上的「重新加载 ↻」→ 刷新交易页面。
- `manifest.json` 里的 `version` 记得同步改（Chrome 靠它判断版本）。

## 功能

- **下单页签**：合约选择、手数、偏移（正=追价/负=挂单）、买开/卖开/买平/卖平、全平、撤单、设置
- **风控页签**：止损止盈（按开仓均价的跳数）、移动止损、按金额算手数、保护单状态
- **持仓页签**：所有持仓 + 权益/可用/保证金/风险度
- **常驻**：3 分钟布林带（1 秒采样成交价，μ±2σ）
- **无全局快捷键**（v1.4.0 起移除，防止误下单）

## 结构

```
manifest.json   MV3 配置；关键是 world:"MAIN"
content.js      全部功能
popup.html/js   工具栏弹窗（版本 + 当前页面检测）
安装说明.txt     Edge / Chrome 安装步骤与常见问题
icons/          16/32/48/128
```

## 为什么必须是 world:"MAIN"

扩展的 content script 默认跑在隔离世界，那里 `sessionStorage` 是空的、`window.__vue__` 不存在，
会导致「面板能显示但下不了单」。`world:"MAIN"` 让脚本注入页面主环境，与页面共享同一份
`window` / `sessionStorage`，从而能读到 `TOKEN` 和交易账号。

代价：需要 Chrome 111+（manifest 里已用 `minimum_chrome_version` 限制）。

## 权限说明

只申请了 `activeTab` —— 仅在你点击工具栏图标时临时读取当前标签页 URL，用来判断
「当前页面是否在支持范围内」。不读浏览历史、不联网、不上传任何数据。

真正的下单请求是脚本在页面内用同源 `fetch` 发的，走你自己已登录的会话。

## 安全说明

本仓库**不包含任何凭据**：代码里没有硬编码的账号、密码或 API Token。登录令牌
（`sessionStorage.TOKEN`）与交易账号都是**运行时**从你已登录的页面中读取，仅存在于
你本机的浏览器会话里，不会被写入仓库或上传到任何服务器。

发布前请注意：`content.js` 属于页面注入型脚本，任何人拿到你的代码都能看到它的实现
细节。若你不希望他人直接使用，请将 GitHub 仓库设为 Private。
